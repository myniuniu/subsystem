## 消息中心架构概述

消息中心采用React函数式组件架构，由`MessageCenter`作为主容器组件，集成`ContactList`（联系人列表）和`ChatWindow`（聊天窗口）两个核心子组件。该架构通过props传递实现组件间通信，维护全局消息状态和联系人状态。

```mermaid
graph TD
A[MessageCenter] --> B[ContactList]
A --> C[ChatWindow]
B --> D[联系人数据]
C --> E[消息历史记录]
A --> F[消息输入处理]
```

## 组件通信协议与数据流设计

消息中心组件与聊天界面组件之间通过props进行数据传递和事件回调。`MessageCenter`组件负责维护全局状态，包括联系人列表、消息历史记录、当前激活联系人等，并将这些状态作为props传递给`ChatWindow`组件。

```mermaid
sequenceDiagram
participant MessageCenter as 消息中心
participant ChatWindow as 聊天窗口
MessageCenter->>ChatWindow : 传递messages, activeContact等props
ChatWindow->>MessageCenter : 调用onSendMessage回调
MessageCenter->>MessageCenter : 更新消息历史记录
MessageCenter->>ChatWindow : 重新渲染更新后的消息
```

## 消息发送与接收流程

消息发送流程始于用户在聊天窗口输入消息并触发发送操作。系统创建包含时间戳、发送者信息和内容的消息对象，将其添加到对应联系人的消息历史记录中。

```mermaid
flowchart TD
Start([用户输入消息]) --> ValidateInput["验证输入内容"]
ValidateInput --> InputValid{"输入有效?"}
InputValid --> |否| End([结束])
InputValid --> |是| CreateMessage["创建消息对象"]
CreateMessage --> UpdateHistory["更新消息历史记录"]
UpdateHistory --> ClearInput["清空输入框"]
ClearInput --> SimulateReply["模拟对方回复"]
SimulateReply --> End
```

## 消息状态管理与未读计数

系统通过联系人数据中的`unreadCount`字段管理未读消息状态。当用户切换到某个联系人时，该联系人的未读计数会被重置为零。总未读消息数通过聚合所有联系人的未读计数获得。

```mermaid
classDiagram
class Contact {
+string id
+string name
+string type
+string avatar
+string lastMessage
+string lastTime
+number unreadCount
+boolean online
}
class Message {
+number id
+string senderId
+string senderName
+string content
+string time
+string type
}
Contact "1" *-- "0..*" Message : 包含
```

## 联系人列表与聊天窗口交互

联系人列表与聊天窗口通过`activeContact`状态变量实现联动。当用户在联系人列表中选择一个联系人时，`onContactSelect`回调函数被触发，更新当前激活的联系人，从而切换聊天窗口显示的内容。

```mermaid
sequenceDiagram
participant ContactList as 联系人列表
participant MessageCenter as 消息中心
participant ChatWindow as 聊天窗口
ContactList->>MessageCenter : onContactSelect(新联系人ID)
MessageCenter->>MessageCenter : 更新activeContact状态
MessageCenter->>ChatWindow : 传递新的activeContact和消息
ChatWindow->>ChatWindow : 重新渲染聊天界面
```

## 消息历史记录管理

消息历史记录以对象形式存储，键为联系人ID，值为该联系人的消息数组。系统提供`getCurrentMessages()`函数获取当前激活联系人的消息记录，并在发送新消息时使用函数式更新模式确保状态不可变性。

```mermaid
erDiagram
CONTACT ||--o{ MESSAGE : 包含
CONTACT {
string id PK
string name
string type
string avatar
string lastMessage
string lastTime
int unreadCount
boolean online
}
MESSAGE {
int id PK
string senderId FK
string senderName
string content
string time

}
```

## 用户界面交互功能

系统实现了多种用户界面交互功能，包括回车发送消息、搜索联系人、模板选择等。其中，回车发送消息功能通过`handleKeyPress`事件处理器实现，而模板选择功能则通过模态框展示各类写作模板供用户选择。

```mermaid
flowchart TD
A[用户操作] --> B{操作类型}
B --> |回车键| C[发送消息]
B --> |搜索输入| D[过滤联系人]
B --> |点击模板| E[插入模板提示]
B --> |选择联系人| F[切换聊天窗口]
C --> G[更新消息历史]
D --> H[显示匹配联系人]
E --> I[填充输入框]
F --> J[加载对应消息]
```
